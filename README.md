# real-estate-platform
Scalable, cloud-native real estate rental platform built with Next.js, Node.js, and AWS.
Features secure authentication with AWS Cognito, geospatial property search using Mapbox and PostGIS, a modular REST API, and a modern, type-safe frontend with Redux Toolkit, Tailwind CSS, and Shadcn UI. Deployed on AWS using EC2, RDS, S3, API Gateway, and Amplify, following production-ready architecture and cost-aware cloud practices.
